# Welcome to indiapins's documentation!

## About

Indiapins is a Python package for getting the places tagged to particular Indian pincode. Updated with the latest February 2026 data containing **165,627 pincode records** across India.

Currently it supports, following operations:

- Validity of Pincode
- Get coordinates related to that Pincode
- Get all details of a pincode
- Get name of district by pincode
